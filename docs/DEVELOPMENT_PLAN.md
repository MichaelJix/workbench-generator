# 自托管 v1.0 开发计划

## 完成定义

v1.0 必须同时满足以下条件：

1. 所有 Spec 带版本号，旧版 Spec 可自动迁移且不会静默丢失字段。
2. 连接器通过统一适配器注册，不在 MCP、HTTP 路由或业务服务中硬编码平台分支。
3. 用户、令牌、访谈、工作台版本、审批请求、OAuth 凭据和审计日志持久化到 SQLite。
4. 支持一句话创建访谈、逐步回答、生成 Spec、保存工作台、修订和回滚。
5. 所有外部写操作必须先创建审批请求，审批后才能执行，且全程写审计日志。
6. 同时提供本地 stdio MCP 和带 Bearer 认证的 Streamable HTTP MCP。
7. 提供自托管 HTTP API、最小管理界面、Docker 部署、健康检查与备份说明。
8. 单元、集成、HTTP 全局和 MCP 端到端测试全部通过，生产依赖无已知漏洞。

## 阶段门禁

| 阶段 | 交付物 | 通过条件 |
|---|---|---|
| A 基础架构 | Spec 迁移、错误码、连接器适配器 | 单元测试覆盖所有迁移和错误分支 |
| B 状态服务 | SQLite、认证、访谈、版本管理 | 重启后数据保持，越权访问被拒绝 |
| C 安全动作 | 审批、OAuth、凭据加密、审计 | 未审批不可执行，审批不可重放 |
| D 接口 | HTTP API、stdio/HTTP MCP、管理 UI | 两种 MCP 传输和 REST 全局测试通过 |
| E 发布 | Docker、CI、文档、分析报告 | 干净环境安装、测试、打包均通过 |

## 明确不包含

- 托管 SaaS、计费、组织级 SSO、跨节点分布式会话。
- 内置第三方 OAuth Client ID/Secret。
- 未经审批的外部写操作。
- 对公网部署的自动 TLS 证书签发；建议由反向代理完成。
